# docs/rules/ — ルール仕様（確定済み）

『王への請願』のルールを実装用に整理したもの。**実装はこのフォルダを唯一の参照先とする。**

| ファイル | 内容 |
|---|---|
| `00-source.md` | 出典と取り込み記録 |
| `01-overview.md` | ゲームの目的・準備・ターンの流れ・カード使用ルール |
| `02-cards.md` | **キャラクターカード20種の獲得条件と効果**（`src/game/cards.js` の元データ） |
| `03-endgame.md` | 最終段階・最終ラウンド・勝敗判定 |
| `04-solo.md` | ソロ用ルール（本アプリ独自の設計） |
| `99-faq.md` | 原典に明記がなく実装側で判断した点の一覧 |

カード画像は `../../assets/cards/`（カードIDと同名の `.jpg`）。

## 実装時の注意

- **「好きなところでストップ」はできない。** 全ダイスが確定するまで振り続けるのが原典のルール（`01-overview.md`）。
- カード効果の対象は原則 **未確定（アクティブ）のダイス**。
- 判定は「その条件を満たす組み合わせが出目に含まれるか」で行う（`02-cards.md` 末尾の表）。
- 原典に無い判断を新たにしたら、必ず `99-faq.md` に追記すること。
