# 03 — 終了条件と最終ラウンド

出典: BSW版ルール翻訳（`00-source.md` 参照）。

## 最終段階への移行

1. **国王のキャラクターカードを獲得したプレイヤーが現れたら** 最終段階に入る
2. まず、**そのラウンドを最後まで通常通りプレイする**
3. その後、**最終ラウンド** に入る

## 最終ラウンド

- プレイ順は通常のルール通り。ただし **前のラウンドで国王を獲得したプレイヤーは一番最後**
- 最終ラウンドは **国王カードを奪うことが唯一の目的**。
  同じ目のダイスをなるべく多くすることを目指す

### 出目の強さ（強い順）

1. **同じ目のダイスの数が多い** ほうが勝ち
2. 同数の場合、**ダイスの目が大きい** ほうが勝ち
3. 上記2つが同じ場合、**先にダイスを振ったほう** が勝ち

最初に国王を獲得したプレイヤーの出目が基準になり、
より強い目を出したプレイヤーへ国王カードが移動する。

## 最初に国王カードを獲得したプレイヤーの特典

- **王妃カードを国王カードと一緒に獲得する**（王妃カードは移動しない）
- **最終ラウンドの手番が最後** になる
- 最終ラウンドで、**最も強い目と同じ強さの目でも国王カードを奪い返す**

## ゲーム終了

最終ラウンドを終えた時点で **国王カードを持っていたプレイヤーの勝ち**。

原典に記載: 「ありません。」
