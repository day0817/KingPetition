**このファイルが `src/game/cards.js` の元データ。** 画像は `../../assets/cards/${カードID}.jpg`。

凡例
- **種別 `常時`** … 持っているだけで効く（手番の最初に振るダイス数が増える）
- **種別 `1回`** … 1手番に1回使用できる
- 効果の対象は原則 **未確定（アクティブ）のダイス**

## 出典の補足（原文ママ）

> １１１１、２２２２等は同じ目が４つかつ２ペアとして扱う。
> ６６６６だと狩人も天文学者も取れるし、
> ２２２２２だと騎士も女官も取れるし、
> ５５５５５５だと司教も貴族も将軍も取れる。

→ **判定は「その条件を満たす組み合わせが出目の中に含まれるか」で行う。**
　 排他的に分割する必要はない。実装時の判定規則:

| 条件 | 判定 |
|---|---|
| 同じ目がN個 | いずれかの目の個数 ≧ N |
| ペアがN組以上 | Σ floor(各目の個数 ÷ 2) ≧ N |
| フルハウス（女官） | ある目が3個以上 かつ 別の目が2個以上、**または** ある目が5個以上 |
| 3つ同じ組が2つ（貴族） | 3個以上の目が2種類、**または** ある目が6個以上 |
| 全て奇数／全て偶数 | 全ダイスがその条件 |
| 合計N以上 | 全ダイスの合計 |
| 12345 / 23456 / 123456 | その目がすべて出目に含まれる |

## ダイス総数の上限（実装メモ）

- 基本: 3個
- 常時追加: 農夫 +1 / ペテン師 +1 / 将軍 +2 → **最大7個**
- 手番中に追加できる（1回ずつ）: 職人(1) 衛兵(2) 狩人(3) 質屋(4) 騎士(5) 司教(6) 王妃(任意) → **最大+7個**
- → 理論上の最大 **14個**。国王の「7つ同じ目」はこの積み重ねで狙う。
